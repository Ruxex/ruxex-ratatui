# ruxex-ratatui

This repository is a Ruxex-maintained downstream fork of [Ratatui](https://github.com/ratatui/ratatui), including the `ratatui-crossterm` package.
It exists solely to publish the Ruxex-compatible packages to crates.io and support the Ruxex dependency graph.
Changes are intentionally limited to the compatibility work required by Ruxex.

Thanks to the Ratatui maintainers and contributors for their excellent work.
